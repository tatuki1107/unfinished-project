運営が用意したAI制作のサンプル作品です。これはオリジナルの歌詞・楽曲制作案であり、録音済み音源ではありません。

『始発前、台所の灯り』制作ノート　第1稿

一　この曲で残したい風景

一緒に暮らしていた人が引っ越した翌朝。語り手は習慣で湯を二人分沸かし、余った湯を捨てずに魔法瓶へ入れる。別れを大きな出来事として歌うのではなく、誰もいない台所で、自分の一日を自分で始めるまでを一曲にする。
相手との関係は恋人・家族・友人のどれとも限定しない。死別を前提にもしない。「もう帰ってこない」ではなく「今日はここにいない」という距離で書く。最後まで、語り手が相手を忘れたことにはしない。

二　演奏の基準

拍子は4分の4、テンポは四分音符76、仮のキーはDメジャー。72小節で約3分47秒を想定する。歌い手の声に合わせた移調は自由。音域案はA3〜D5だが、メロディー全体は未確定なので、これは完成した採譜ではなく作曲時の目安である。
編成は歌、アップライトピアノ、指弾きベース、小さなドラムセット。弦や大きなシンセパッドで感情を先回りしない。生活音を使う場合は自分で録ったものを使い、実際の個人の会話や放送を無断で混ぜない。

三　小節構成と和声案

1〜4小節：イントロ。Dadd9 / A/C# / Bm7 / Gadd9。右手は高い音を鳴らし続けず、毎小節の終わりに隙間を置く。
5〜16小節：A1。Dadd9 / A/C# / Bm7 / Gadd9 を3回。歌詞は下記の6行を各2小節で扱う。
17〜24小節：B1。Em7 / F#m7 / Gadd9 / Asus4 / Em7 / F#m7 / G / A。ベースがここで初めて独立した旋律を持つ。
25〜36小節：サビ1。D / A/C# / Bm7 / F#m7 / G / D/F# / Em7 / A / G / A / D / D。
37〜40小節：間奏。イントロと同じ4小節。ただし最後はGの第三音を抜き、次の歌が入るまで明暗を決めない。
41〜48小節：A2。Bm7 / F#m7 / G / D を2回。A1より低い音から歌い始める。
49〜52小節：B2。Em7 / F#m7 / G / A。
53〜64小節：サビ2。サビ1と同じ和声で、歌詞の最後だけ変える。
65〜72小節：アウトロ。Dadd9 / A/C# / Bm7 / Gadd9 / Em7 / A / Dadd9 / 休止。最後の8小節を歌で終えるか、楽器だけにするかが主な未完成箇所。

五　歌い方とアレンジの具体案

A1の「二つ分」で急に声を震わせない。語り手はまだ自分の行動を観察している段階なので、泣いていると断定できる歌い方を避ける。「買い足すものだけ」の直前に短く吸い、生活の中に戻る感じを出す。
B1の最後は感情の結論ではない。「置き場所が変わった」という言葉を、自分に言い聞かせているように少し遅らせる案がある。ただしテンポ自体は動かさず、伴奏は一定に保つ。
サビ1で初めてキックを入れる。スネアは強く叩かず、リムを中心にする。ハイハットの細かい刻みはまだ要らない。歌の「持っていく」とベースの下降線がぶつかる箇所は、ベースを一拍休ませると輪郭が残る。
二度目のサビでも転調しない。変化は音量ではなく、主語が「誰か」から「私」へ移ったことに置く。最後のDadd9は長く伸ばせるが、余韻を無限に重ねず、部屋の外へ出たように一度きっぱり切る案も残す。

六　録音する人への受け渡し

最初の試作はピアノと仮歌だけでよい。クリック入りの練習用、クリックなしの試聴用、歌なしの伴奏用を分ける。完成したと報告する際には、使用キー、テンポ、構成を変更した小節、音素材の出所を添える。
現時点で音源・MIDI・楽譜は未作成。コード記号から演奏できることと、歌の旋律が完成していることは別なので、この文章を「既存音源の再現指示」として扱わない。

七　続きを託したいところ

まずメロディーを付けてほしい。特に「扉は今日も」の長い語句が自然に収まることを優先し、必要なら語順の変更も歓迎する。アウトロの二行は残すか削るか決めていない。説明しすぎなら楽器だけで終えてよい。
別の派生では、引っ越した側の朝を歌う二曲目を作れる。ただし、この曲の語り手へ返事を届けて簡単に解決させず、別々に暮らし始めた二人の生活を、それぞれ独立したものとして描いてほしい。
